# NeoPulse — IoT Monitoring Dashboard

NeoPulse is a responsive React-based IoT monitoring dashboard designed to visualize simulated real-time sensor data through a modern and interactive interface.

## Features

- Real-time simulated sensor data
- Temperature, humidity, pressure, battery and air-quality monitoring
- Interactive charts and graphs using Recharts
- Automatic sensor value updates
- Responsive dashboard layout
- Interactive sidebar navigation
- Notification and profile panels
- Smooth UI animations
- Mobile-friendly design

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Recharts
- Framer Motion
- Lucide React

## Project Purpose

This project was developed as part of a Web Developer Internship technical evaluation to demonstrate frontend development, React component design, data visualization, responsive UI development, and interactive user experience.

## Note

The sensor readings displayed in the dashboard are simulated data generated on the client side and do not represent readings from physical IoT devices.
